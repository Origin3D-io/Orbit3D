# License and dependencies

Orbit3D project source is distributed under the [MIT license](../LICENSE).

| Component | Runtime dependencies |
| --- | --- |
| OrbitHub and native SDK | C/C++ runtime and operating-system sockets |
| Python SDK | Python standard library |
| Blender integration | Blender's Python and viewport APIs |
| FreeCAD integration | FreeCAD's Python, Qt, and scene APIs |

Build tools and host applications are not bundled. The example integration archives
include the Python SDK and project license. They contain no USB transport or
third-party runtime binaries.
